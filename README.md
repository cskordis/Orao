# Orao
Orao (en. Eagle) was an 8-bit computer developed by PEL Varaždin in 1984 as a standard primary school and secondary school computer in the former Yugoslavia (Croatia and Vojvodina) from 1985 to 1991.

The original rom was mapped for the Croation keyboard but there was a need to remap it for the North American keyboard layout.

The 16K rom developed here contains the original rom in the first 8K and the modified remapped rom in the last 8K which fits nicely in a 27C256 EPROM

In the ROM section, the file orao-1.3-bascrt-bin.bin is the original Basic rom, where the orao-1_3-bascrt-bin-HRUS.bin file is the modified rom.
